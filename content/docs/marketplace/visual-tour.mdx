# ecosystem.Ai Platform 2.0

**Build Your Own Contextual Interactions — Inside Your Cloud Perimeter.**

**ecosystem.Ai Platform 2.0** combines behavioral social science with real-time machine learning and agentic operations so enterprises can score, personalize, and learn from every customer interaction in the moment. Deployed entirely inside your **Kubernetes 1.37** cluster on **[Microsoft Azure AKS](/docs/marketplace/azure)**, **[Amazon EKS](/docs/marketplace/aws)**, **[Google Cloud GKE](/docs/marketplace/gcp)**, or **[Self-Hosted Kubernetes / Docker Compose](/docs/local)** (supporting both ARM64 and x86_64 AMD64 worker nodes, with **`gpt-6-luna`** configured as the default generative model across all containers), subscriber features, models, and interaction data remain inside your cloud perimeter.

Purpose-built for telecommunications (CVM, next-best-offer, and MVNOs), retail and commercial banking, insurance, retail, and gaming, the platform covers Intelligent Discovery, Smart Engagement, Intelligent Activation, and Proactive Retention.

## Subdomain Routing & Internal Container Communication

Every application in **ecosystem.Ai Platform 2.0** runs at root `path: /` on its own dedicated subdomain (`https://<app>.<baseDomain>/` on Azure AKS, AWS EKS, and Google Cloud GKE, or `http://<app>.localhost/` locally). No sub-path prefixes are used, ensuring SPAs, static assets (`/assets/...`), OAuth callbacks, and API routes resolve cleanly at `/`:

| Service | Subdomain Host (`<baseDomain>` = `<IP>.nip.io`, `<dnsZone>`, or `localhost`) | Pure Origin Env Var | Internal Container-to-Container DNS |
|---|---|---|---|
| **Workbench 2 (Operator UI & Public API)** | `workbench.<baseDomain>` (`/`, `/public/v1`) | `WORKBENCH_PUBLIC_URL`, `WORKBENCH_UI_URL`, `PUBLIC_BASE_URL` | `http://workbench2:5270`, `http://workbench2:8004/public/v1`, `http://workbench2:8001/api/v1` |
| **Prediction Server & Modeling API** | `server.<baseDomain>` (`/`, `/api/v1/health`) | `SERVER_PUBLIC_URL`, `IP` | `http://ecosystem-server:3001`, MongoDB `ecosystem-server:54445`, H2O `http://ecosystem-server:54321` |
| **Runtime 0.9.7 (Real-Time Scoring)** | `runtime.<baseDomain>` / `runtime1.<baseDomain>` (`/invocations`, `/response`, `/mcp`, `/ping`) | `RUNTIME_PUBLIC_URL` | `http://ecosystem-runtime-solo:8091` |
| **Campaign Management** | `campaign.<baseDomain>` (`/`) | `CAMPAIGN_PUBLIC_URL` | `http://ecosystem-campaign:54310` |
| **Data Analysis Agents** | `data-agents.<baseDomain>` (`/`) | `DATA_AGENTS_PUBLIC_URL` | `http://ecosystem-data-agents:54325` |
| **EcoGentic & Notebooks** | `notebooks.<baseDomain>` (`/`) | `NOTEBOOKS_PUBLIC_URL`, `VITE_ECOGENTIC_AGENT_URL` | `http://ecosystem-notebooks:8010` |
| **Custom GPTs / Managed Agents** | `custom-gpts.<baseDomain>` (`/`) | `CUSTOM_GPTS_PUBLIC_URL` | `http://ecosystem-custom-gpts:54320` |
| **Domain Catalog** | `domain-catalog.<baseDomain>` (`/`, `/v1/health`) | `DOMAIN_CATALOG_PUBLIC_URL` | `http://ecosystem-domain-catalog:8080` |
| **EcosystemCode & Modeling UI (`code`)** | `code.<baseDomain>` (`/`, `/health`) | `CODE_PUBLIC_URL`, `VITE_MAIN_SITE_URL` | `http://ecosystem-modeling:5174` |
| **App Builds Supervisor (`builds`)** | `builds.<baseDomain>` (`/health`) + `app-15100..15299.<baseDomain>` | `BUILDS_PUBLIC_URL`, `MODELING_LOCAL_RUNTIME_URL` | `http://ecosystem-app-builds:9099` (`ecosystem-app-builds-mongo:27017`, `ecosystem-app-builds-postgres:5432`) |
| **Trino SQL Engine** | `trino.<baseDomain>` (`/v1/info`) | — | `trino:8080` |

## Operator Workbench & Container Modules — Visual Tour

### 1. AI Project Generation & Architecture Planner
Describe your business goal in natural language — the Ecosystem Agent proposes the complete project configuration, linking feature store lookups, static/dynamic/generative models, offer matrices, and network of recommenders.

![AI Project Generation and Architecture Planner](/images/marketplace/01-generate-project-agent-plan.png)

### 2. Interactive Project Setup & Configuration Notebooks
Inspect, rerun, and patch live project configurations, deployment steps, pre/post-score Java plugins (`DefaultPreScore.java`, `PlatformDynamicEngagement.java`, `DefaultReward.java`), dynamic engagements, and offer matrices directly from Workbench Notebooks.

![Interactive Project Setup Notebook](/images/marketplace/02-project-setup-interactive-notebook.png)

### 3. Agentic Campaign Process Flow Designer
Design and govern multi-stage customer outreach and decisioning pipelines on an interactive process canvas (e.g., `Load bank customers` → `Spend Personality 0.09.9` → `Dynamic message recommender`) with built-in GDPR/CASL/CAN-SPAM compliance controls.

![Agentic Campaign Process Flow Designer](/images/marketplace/03-campaign-process-flow-designer.png)

### 4. Domain Ontology Hierarchy & Systems-of-Record Mapping
Explore governed OWL/SKOS/SHACL domain ontologies (`CRM`, `CVM`, `Banking`, `Insurance`, `Retail`, `Gaming`), subclass/alignment graphs, and physical table/collection mappings (`owl:equivalentClass`) in `ecosystem-domain-catalog`.

![Domain Ontology Hierarchy and Systems-of-Record Mapping](/images/marketplace/04-domain-ontology-hierarchy-graph.png)

### 5. Custom GPTs & Domain-Grounded Managed Agents
Interact with specialist RAG and domain-grounded managed agents (such as `AI Posture Archetypes`) backed by custom knowledge bases and live runtime context.

![Custom GPTs and Managed Agents](/images/marketplace/05-custom-gpts-managed-agents.png)

### 6. Spend & Money Personality Behavioral Drift Analytics (`/analytics/`)
Track customer personality archetypes (`Intentional`, `Industrious`, `Experiential`, `Enthusiastic`), behavioral drift magnitude, label/trait transitions, and biggest movers across time windows.

![Spend and Money Personality Analytics](/images/marketplace/06-spend-money-personality-analytics.png)

### 7. Computational Social Science Network Graph Analysis (`/networks/`)
Run PageRank, Betweenness/Closeness/Degree/Eigenvector/Katz centrality, and Louvain community detection over customer segments, credit bureau bands, and runtime interaction topologies.

![Computational Social Science Network Graph Analysis](/images/marketplace/07-computational-social-science-network-graph.png)
