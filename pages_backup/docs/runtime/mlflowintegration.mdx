# MLFlow Integration

Runtime **0.9.7** does not pull models from MLflow automatically. Log the MOJO in MLflow, download it, place it in the runtime model path, then call [`/refresh`](/docs/runtime/access) on the runtime to reload.

In-platform training: [MLRun module](/docs/modules/mlrun) in Workbench2.

Full steps and example: [MLFlow Integration](/docs/runtime/mlflowintegration) in the current docs site.
